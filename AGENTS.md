# Instruccions de treball

- Respon en català, amb explicacions concises.
- Abans de treballar, llegeix `docs/ESTAT_ACTUAL.md` i `docs/PENDENTS.md`; les decisions vigents substitueixen les propostes històriques.
- Preserva els canvis locals, els identificadors, els vincles i les dades existents. No descartis feina ni facis force push.
- Avisa abans de preparar tasques que requereixin SQL/RPC/migracions a Supabase i espera l’autorització corresponent. No executis SQL remot ni modifiquis registres sense autorització explícita per a aquella operació.
- Prova amb dades sintètiques. No repeteixis migracions ja aplicades ni executis reversions per publicar el client.
- No incorporis secrets, dades personals, informes reals, CSV/ZIP, plans ni materials de recuperació al repositori públic. Els materials privats es custodien fora del repositori.
- Executa els controls pertinents; després dels canvis, indica què s’ha comprovat, les limitacions i passos concrets per revisar-ho al navegador. Les proves automàtiques no substitueixen les manuals ajornades.
- Publica només dins de l’abast autoritzat; comprova remot, controls, GitHub Actions i recursos servits per Pages. No donis per verificades interaccions autenticades sense provar-les.
